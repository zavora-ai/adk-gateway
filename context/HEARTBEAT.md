# Heartbeat Checklist

This runs every 30 minutes. Follow it strictly.

## Check
- Any pending tasks or follow-ups that need attention?
- Any scheduled tasks that failed or need review?
- If it's daytime, do a lightweight check-in if nothing else is pending.

## Rules
- Keep responses short (1-2 sentences max).
- If nothing needs attention, reply with just: HEARTBEAT_OK
- Do NOT repeat old tasks from prior conversations.
- Do NOT invent tasks that weren't explicitly requested.
- Only alert if something genuinely needs the user's attention.
