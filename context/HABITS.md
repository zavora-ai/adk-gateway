# Habits & Routines

Track daily routines, goals, and behavioral patterns.
The agent can use this to provide timely nudges and track progress.

## Format

Each habit entry should include:
- **Habit**: What the user wants to do
- **Frequency**: daily / weekly / as-needed
- **Status**: building / established / lapsed
- **Notes**: Context, triggers, progress
